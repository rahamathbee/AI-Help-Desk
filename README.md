# 🎓 GENAI Academic Helpdesk

## 📖 Project Overview

GENAI Academic Helpdesk is a simple AI-inspired web application that helps students get instant answers to common academic questions. Users can either click quick-access buttons or type their own questions into the chat box.

The application provides information about:

- 📚 Library
- 💼 Placements
- 🏠 Hostel
- 📝 Exams
- 💰 Fees
- 📅 Attendance

---

## 🚀 Features

- Modern and responsive user interface
- AI chatbot-style conversation
- Quick question buttons
- User and bot chat messages
- Automatic scrolling
- Press Enter to send message
- Simple keyword-based response system
- Beginner-friendly source code

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click **index.html**
   OR
4. Open it using **VS Code** and run with **Live Server**.

No installation is required.

## 💬 Sample Questions

- What is library timing?
- What is placement eligibility?
- What are hostel rules?
- When do exams start?
- What is the fee structure?
- What is the attendance requirement?

---

## ⚙️ Working

1. User clicks a quick button or enters a question.
2. JavaScript checks the question.
3. A matching response is generated.
4. The chatbot displays the answer in the chat window.
